模块单一职责可依赖测试方式
cli参数解析、子命令分发、envelope、退出码service子进程 + envelope schema
service事务编排：scan/deepdive/match/report set/event add/stream register；把事实快照交给纯函数policy adapter launcher normalize rules validate panel importer store临时库 + mock adapter
policy网络门禁：canonical profile 文件锁、预占动作、滚动预算、冷却、逐响应风控判定store config注入时钟/随机源；第二页 31/37 无第三次导航
adapter关联本次 tab 的目标响应；typed success/empty/blocked/unauth/unknown；映射前保存条目vendor合成响应/页面 fixtures
launcher受限参数启动专用 Chrome；校验回环与归属；stopconfig参数快照 + 监听校验负例
normalize纯函数：条目 → 标准事实；薪资单位/币种/薪数；枚举；未知为 NULL无表驱动单测
rules纯函数：条件树、first-match、计分组封顶、unknown 传播；受限 worker 超时无legacy 私有回归 402 / 478；边界用例
validate纯函数：JSON Schema + 语义（预算上限、升版兼容、引用存在于给定快照）无正反样例
store唯一数据库访问层：迁移、固定视图、预定义参数化查询、事务config迁移幂等；FK；并发写
panel固定视图 → 单文件 HTML；上下文转义；固定可信筛选脚本；无外部资源store validate快照 + 恶意内容 + 无外链
importer历史 JSON → import run；legacy_mapped；(file_sha256,item_index) 幂等store normalize1260/1225；重导不增
vendor上游最小原语（CDP 会话、捕获）；固定版本、不修改websocket-client requests上游测试 + 合成
依赖方向：cli → service → {policy, adapter, launcher, normalize, rules, validate, panel, importer} → {store, vendor} → config。import-linter 断言，禁止反向。
数据库：只有 store 可 import sqlite3；其他模块只拿 store 暴露的函数。
LLM：任何模块不得 import LLM SDK；pyproject 无相关依赖。
可注入：时间、随机源、网络适配、文件路径均可注入；rules/normalize/validate 不访问网络与数据库。
发行：源码包按 allowlist 打包；发布前扫描真实导航关联值、真实标识、个人信息；真实回归只走私有 manifest。
