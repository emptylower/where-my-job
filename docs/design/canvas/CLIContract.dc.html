P2 · CLI 接口契约（设计 v3 §8）
所有命令支持 --json：stdout 只有一个 envelope 对象；日志与进度到 stderr；所有输入在使用时强制校验
组命令作用与边界退出码
环境init [--browser] [--probe]默认仅本地：依赖、目录、迁移。--browser 由 launcher 拉起专用空白 Chrome，用户手动登录。--probe 是显式且受门禁的主动探测0/1/2/3
status [--json]数据/评分/报告状态、任务统计、锁、预算、冷却到期、保留策略与体积；仅本地读取0
browser stop只停止本工具验证归属的专用浏览器，关闭调试入口0/2
数据import FILES... [--manifest F]显式清单；legacy_mapped 标记；(file_sha256,item_index) 幂等；来源时间与时区假设记录；不导入分数0/1/4
scan --strategy F [--dry-run]展开并校验任务计划（超 80 页或额度不足直接报错）；受控列表采集；逐响应判风控；逐条落库。dry-run 不访问 BOSS0/1/2/3/4
deepdive JOB_ID [--cached] [--skip-company]持锁采集两页或读缓存包；创建 evidence 与不可变 bundle；返回 bundle_id 与 acquisition_state；skip-company 显示公司页未采集0/1/2/3/4
evidence add JOB_ID --file F校验并保存站外/用户证据；origin 默认 agent，不信任自报 cli；无 URL 须 kind=user_statement0/1
evidence list/show ID [--local-out F]受限字段与摘录；完整原文只写显式本地文件，stdout 只给路径0/1
匹配match [--scoring F] [--as-of T]固定快照计算，事务提交一个 match_run；失败保留旧批次0/1
标注attr set/get/list/unsetpriority / note / score_adjustment / custom.*；source agent|user；保留名不能绕过 report/match 协议0/1
报告report set JOB_ID --file F结构化报告一次事务提交：bundle_id、证据引用、三值结论、可空信号数组、非空 Markdown、幂等键；两项标注由报告投影0/1
report get JOB_ID [--report-id ID]当前或历史报告、绑定证据、report_state 与过期状态0/1
事件event add --file F文件含流、绑定版本、类型、主体、payload、幂等键；首次 applied 同事务建身份；corrected 为保留控制类型（replace/retract）0/1
event list --stream S [--subject ID] [--history]有效时间线；--history 含纠错与撤销记录0/1
stream register --file F / list / show S [--revision N]register 校验并激活不可变版本；validate 不激活；升版只增不改0/1
查询job list [--filter K=V ...] [--sort] [--page] / job show JOB_ID固定参数的公开字段读取、筛选、分页；用户输入不成为 SQL 片段。v1 无自由 SQL0/1
展示panel [--spec F] [--open] [--out F]固定视图 + 类型化筛选 + 可选注册流时间线 tab；原子替换的自包含 HTML；无外部资源0/1
校验validate {profile,strategy,scoring,panel,evidence,report,event,stream,settings} FJSON Schema + 语义错误（字段路径、允许值）；不采集、不激活0/1
清理data delete --job ID | --all [--dry-run] / data prune --raw-before T [--dry-run]删除清理关联业务数据与受管派生产物；prune 用户显式触发、必须给时间参数、不自动调度；均不重置网络策略状态0/1/2/4
码含义agent 行为
0所声明的本次操作完整成功；正常空结果也可成功继续；采集成功 ≠ 分析完成
1用法、配置、类型或语义校验失败按字段路径修改后重试；命令仍会再校验
2环境/依赖/本地资源：未登录、CDP 不通、端口归属错误、无写权限；采集失败且无任何有效结果时也按失败类别归此告知修复步骤；不自动重复爬取
3风控、冷却、滚动预算耗尽、浏览器会话被占用（RESOURCE_BUSY）读细分 code；停止网络工作；不并发绕过；有部分数据也不降成 4
4计划未完成或部分输入失败，但已保存部分有效结果展示已完成/未完成；新尝试是新 run + parent_run，用户决定后再启动

run 终态：ok / blocked / partial / failed / cancelled；处理中 running；遗留 running 在下次启动标 interrupted。
并发：scan / deepdive / probe 共用一把按 canonical profile 的文件锁；只读命令可并发。
兼容：命令名、参数名、退出码、envelope 顶层字段在 v1.x 内不变；data 按各命令 versioned schema。
输出体积：证据包默认 ≤64KiB，省略 raw、security_id/lid、招聘者标识、profile 全文。
