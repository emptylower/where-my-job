架构决策记录（ADR）
ADR-1 形态：确定性 CLI + SKILL.md；agent 单向调用；CLI 不调用 LLM
ADR-2 数据：固定核心层 + 受约束标注层 + 声明式事件流；无用户 DDL
ADR-3 策略、规则、面板、流声明全部为版本化 JSON，validate 与 register 分离
ADR-4 采集：自有 adapter 在映射前保存 api_entry；vendor 只复用低层原语
ADR-5 网络：统一门禁、逐响应判风控、持久预算与冷却、同 profile 单锁
ADR-6 证据：不可变 bundle + 原子 report set；结论三值且标推断，无百分比
ADR-7 站外调查归 agent；CLI 只做站内两页
ADR-8 v1 无自由 SQL；固定视图与预定义查询
ADR-9 公开制品只含合成数据；真实回归私有
ADR-10 留存默认不过期，只有手动清理
ADR-11 隐私承诺限于 CLI 自身；agent 出站由用户环境决定并在访谈前告知
